# HERBORA — Herbal Knowledge Website

เว็บไซต์ตัวอย่างฐานข้อมูลสมุนไพรและภูมิปัญญาท้องถิ่น พัฒนาด้วย HTML, CSS และ JavaScript แบบไม่ต้องติดตั้งไลบรารีเพิ่ม

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด VS Code
3. เลือก File > Open Folder แล้วเลือกโฟลเดอร์ HERBORA
4. ติดตั้ง Extension ชื่อ Live Server (ถ้ายังไม่มี)
5. คลิกขวาที่ index.html แล้วเลือก Open with Live Server

หากไม่ต้องการติดตั้ง Live Server สามารถดับเบิลคลิก index.html เพื่อเปิดในเบราว์เซอร์ได้เช่นกัน

## โครงสร้าง
- index.html — โครงสร้างหลักของเว็บ
- css/style.css — สี รูปแบบ และ Responsive Design
- js/herbs.js — ข้อมูลสมุนไพรตัวอย่าง
- js/app.js — เปลี่ยนหน้า ค้นหา แสดงรายละเอียด และจัดการข้อมูล

## ฟังก์ชันในเวอร์ชันนี้
- หน้าแรกและเมนูแบบ Single Page
- ค้นหาชื่อสมุนไพรและสรรพคุณ
- เลือกดูตามหมวดหมู่
- หน้ารายละเอียดสมุนไพร
- เพิ่ม แก้ไข และลบข้อมูล
- เก็บข้อมูลใน localStorage ของเบราว์เซอร์

## ข้อจำกัด
ข้อมูลที่เพิ่มผ่านหน้าจัดการจะถูกเก็บไว้ในเบราว์เซอร์เครื่องนั้น ไม่ได้ซิงก์ข้ามอุปกรณ์ และไม่มีระบบล็อกอิน/สิทธิ์ผู้ดูแลระบบ หากต้องการใช้งานหลายคนร่วมกันต้องเพิ่ม Backend และฐานข้อมูลภายหลัง

ภาพประกอบและฟอนต์บางส่วนโหลดจากอินเทอร์เน็ต หากไม่มีอินเทอร์เน็ตอาจแสดงภาพสำรองหรือฟอนต์ของเครื่องแทน

ข้อมูลสมุนไพรในตัวอย่างมีไว้เพื่อการศึกษาเท่านั้น โปรดตรวจสอบข้อมูลทางวิชาการและข้อควรระวังก่อนนำไปใช้จริง
